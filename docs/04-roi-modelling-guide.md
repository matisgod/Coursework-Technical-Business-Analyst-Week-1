# ROI Modelling Guide

For Phase 1 Deployment, it is recommended to execute a coordinated implementation of OPP-03 (Centralized CRM Integration), OPP-04 (Systemic PTP Ledger), and OPP-05 (Automated Triage & Routing) as a single core project block.

Strategic Justification
The Technical Dependency: Implementing the outreach engine (OPP-02) or compliance logs (OPP-06) first provides minimal value if the underlying customer history data remains fractured across four systems. OPP-03 must launch first to merge the legacy database, emails, and spreadsheet trackers into a single interface.

The Immediate Business Payback: Once the centralized data layer is active, layering in OPP-04 and OPP-05 immediately triggers the business's largest cash-generation and labor-saving functions. OPP-04 structurally blocks the 14% missed follow-up leakage (securing the £2.4M annual recovery uplift), while OPP-05 automatically fast-tracks the 38% straightforward portfolio through the new system, dropping simple handling times from 18 down to 10 minutes.
